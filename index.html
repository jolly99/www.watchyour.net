Architecture

Designed for real production WLANs.

WAM uses modern APIs and telemetry rather than screen scraping. Collection is vendor-specific; presentation and assurance are normalized.

  • Cisco Catalyst 9800: streaming telemetry with RESTCONF reconciliation and fallback.
  • ArubaOS 8: Mobility Conductor discovery plus direct Managed Device operational collection.
  • PostgreSQL / TimescaleDB: operational state and historical metrics.
  • FastAPI + React: responsive API-driven application architecture.
  • Docker Compose: predictable installation, upgrades, and service isolation.
